字幕遮挡器

双击桌面的“字幕遮挡器”快捷方式启动。
1. 拖动矩形框到字幕区域，拖动边缘或角落改变尺寸。
2. 在设置窗口输入宽度和高度，调节“高斯模糊”和“加深遮挡”。
3. 勾选“锁定位置，鼠标可穿透”，即可继续点击框下的视频。
4. 最小化设置窗口后，它会收进系统托盘；双击托盘图标可恢复。
5. 关闭设置窗口或在托盘菜单选择“退出”，会完全退出软件。

快捷键
Ctrl + Alt + L：锁定 / 解锁
Ctrl + Alt + H：显示 / 隐藏遮挡框
Ctrl + Alt + S：打开设置

设置保存在软件旁的 settings.xml，下次启动会恢复。
软件离线运行，仅在内存里处理矩形区域及其模糊边缘的屏幕画面，不保存或上传画面。
若字幕仍可辨认，请增大模糊强度或加深遮挡；加深至 100% 为纯黑遮挡。
适用于普通窗口和无边框全屏；独占全屏播放器请改用窗口或无边框全屏。
某些受保护的视频无法被系统捕获，模糊区域可能显示为黑色。

实现说明
实时截取背景并执行两次可分离高斯卷积，采用降采样控制负载。
使用 Windows 的 WDA_EXCLUDEFROMCAPTURE 将遮挡窗口排除在自身捕获之外，防止重复模糊。
API 文档：https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity
源代码：SubtitleBlur.cs（C# / Windows Forms / .NET Framework）
